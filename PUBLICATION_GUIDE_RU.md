# Как опубликовать четыре версии TSI на GitHub

Пакет создан 10 октября 2026 года. Репозиторий `Muhomor2/TSI-CORE` **не создан автоматически этим архивом**.

1. Войдите в GitHub под `Muhomor2` и откройте https://github.com/new.
2. Укажите имя `TSI-CORE`. До завершения заключительного аудита удобнее выбрать **Private**, а когда материалы готовы к открытому обсуждению, сделать **Public**; допустимо и сразу открыть публичную RC2 с точным предупреждением о статусе.
3. Создайте репозиторий без начальных README/лицензии (они уже находятся в архиве; лицензия пока не выбрана).
4. Загрузите файлы и папки **изнутри** архива, сохранив пути `docs/`, `science/`, `popular/`, `verification/` и `history/`. На телефоне удобнее воспользоваться GitHub через браузер в режиме компьютера либо поручить добавление текстовых файлов подключённому инструменту GitHub после создания репозитория.
5. Первую публикацию отмечайте `1.0-RC2-prepublication` и текстом `NOT MACHINE VERIFIED`; не используйте `FINAL`.
6. Независимый аудит и машинная верификация предшествуют заявлению о верифицированном релизе.
7. Для Zenodo выпускаются проверенный GitHub release, PDF научных документов и подтверждённые библиографические метаданные. DOI появляется только после регистрации, его не нужно придумывать.

## Что увидит читатель

На главной странице README будут четыре ссылки:

| | Русский | English |
|---|---|---|
| Научная | `science/TSI-CORE-1.0-RC2-SCIENTIFIC-RU.md` | `science/TSI-CORE-1.0-RC2-SCIENTIFIC-EN.md` |
| Простая | `popular/TSI-CORE-1.0-RC2-EXPLAINED-RU.md` | `popular/TSI-CORE-1.0-RC2-EXPLAINED-EN.md` |

`docs/TSI-CORE-1.0-RC2.md` — исходный канонический текст. Его формулы не изменены.

## Лицензия

При отсутствии файла LICENSE публикация на GitHub не означает свободное право на использование материалов третьими лицами. Если нужна возможность академического цитирования, переработки и распространения с указанием автора, можно отдельно выбрать CC BY 4.0 для текста. Выбор делает автор; этот пакет не содержит самовольного решения за него.
